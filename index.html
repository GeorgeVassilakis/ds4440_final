About This Project

How It Works

This music recommender system uses embeddings generated from audio features to find similar songs. The system was created using the following process:

  1. Extracted audio features from songs using a variety of acoustic measures (MFCC, energy, spectral features, etc.)
  2. Trained an autoencoder neural network to generate 16-dimensional embeddings that capture the essence of each song
  3. Computed similarity scores between songs based on the cosine similarity of their embeddings
  4. Created this website to make recommendations based on the pre-computed similarity matrix

Technical Details

The system uses:

  • Audioanalysis features extracted with acoustic processing techniques
  • Deep learning with PyTorch to create song embeddings
  • Dimensionality reduction to create a compact song representation
  • Cosine similarity to measure song similarity
